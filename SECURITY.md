# Security policy

Do not include credentials, private artifact contents, or exploit details in a
public issue.

Use GitHub's private vulnerability-reporting flow when it is available. If the
repository does not show a private reporting option, open a minimal issue asking
the maintainer for a private contact channel without describing the
vulnerability.

MikoMarkup treats agent output as untrusted. A report should say whether the
issue affects request construction, DOM preview sanitization, server-side agent
execution, or host persistence.
