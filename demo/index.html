MikoMarkup

Comment on any HTML. Let your agent update it.

Keep the artifact viewer you already have. Add selection, anchored feedback, agent handoff, and an in-place preview with one browser-side SDK.

01 · Select

Point at the exact section

Click a section and add its comment, then repeat anywhere else in the artifact. Stable IDs, CSS paths, and text quotes travel together so an agent does not have to guess what “the box near the top” means.

02 · Comment

Describe the change in context

Each comment keeps its selected anchors. Queue feedback across the artifact, then send one compact request instead of copying screenshots and manually describing every location.

03 · Agent

Use whichever harness already runs your code

The SDK calls a plain async adapter. That adapter can use Codex, Claude Code, Miko, a local model, MCP, or your own service without changing the browser integration.

createArtifactReview({
  root: "#artifact",
  adapter: createFetchAdapter({
    endpoint: "/api/agent/edit-artifact"
  }),
  onApply: saveArtifact
}).enable()

04 · Review

Preview the update where it belongs

The proposed patch appears in the open artifact. Accept it to call the host’s save function, or discard it while keeping the original comments for another pass.
